Worse Speech:An Objective-Subjective Ranking Reversal in BigVGAN-Style Discriminator Ablations

Does a generator with periodic activations still benefit from a multi-period discriminator?

We compare MPD+MRD with MRD-only supervision in a shared BigVGAN-style generator, using Snake and LeakyReLU activations. On the fixed listening stimuli, the evaluated reference-based metrics favor MRD-only on average, while listeners and UTMOS favor retaining MPD. Both activation conditions retain the generator’s anti-aliasing operations.

Objective evaluation on the same 20 utterances

The eight reference-based measures favor MRD-only in their means under both activation settings. The learned, non-reference predictor UTMOS22 strong favors MPD+MRD. This is a disagreement between evaluation perspectives, not a claim that all automatic evaluation fails.

Each metric uses 20 common valid utterances per pair. Direction-adjusted Δ is positive when MPD+MRD is better. Its 95% intervals use a paired-utterance percentile bootstrap with 20,000 resamples. Snake pitch error’s interval includes zero. These intervals differ from the listener-level intervals above.

03 / Experimental scope

A controlled discriminator ablation.

Shared generator

A direct-waveform, BigVGAN-style backbone with Snake or LeakyReLU. Anti-aliasing remains in both. The discriminator comparison retains MRD and either includes or removes MPD.

Training & selection

LibriTTS train-clean-100, Colab A100, batch size 32, seed 1234, and 500 epochs. Checkpoints were selected within the final epoch using the lowest recorded generator total loss in each run.

Fixed listening set

One utterance per speaker from 20 speakers, sampled using reference duration (3–6 seconds) and file availability, not model-quality scores. Two instructed-response attention checks were included per task.

The main factorial comparison uses one selected checkpoint per configuration. Applying the same within-run checkpoint rule does not make differently composed total losses an identical quality criterion.
